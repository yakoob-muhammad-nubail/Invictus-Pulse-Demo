
# Invictus Pulse

Invictus Pulse is a business operations and lead management platform designed for service-based companies such as contractors, consultants, clinics, and real estate teams. The platform combines CRM functionality, Google Places lead generation, Gmail integration, analytics, and workflow automation into a single dashboard.

Users can discover businesses without websites, manage outreach pipelines, track client communications, monitor proposals and follow-ups, and view real-time business analytics. Invictus Pulse integrates with services like Google Places and Gmail to automatically collect leads, sync relevant client emails, and organize operational data across teams and organizations.

# env
Create an env file with the following api keys
    - supabase url
    - supabase service role key
    - google client id
    - google client secret
    - google redirect uri
    - google places api
